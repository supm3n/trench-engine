# Contributing

Thank you for helping to make Entente Engine better.

## Bug reports and ideas

Both are very welcome on the [Issues page](https://github.com/supm3n/trench-engine/issues/new/choose):

- **Bug report:** something crashes, looks wrong or plays differently from the original game. Please attach the crash
  report and the newest log (the form says where to find them).
- **Idea:** something you would like to see, in the standard rules or in [Entente Engine Plus](docs/PLUS.md).

Please check first whether someone has already reported the same thing, and if so, add to that issue instead.

Changes to the game's balance go into Entente Engine Plus, not into the standard rules, which stay as close to the
original as the bug fixes allow.

## Pull requests

Because of the licence ([PolyForm Strict 1.0.0](LICENSE)), we cannot accept pull requests with code changes for now.
If you found the cause of a bug in the code, please describe it in an issue, with the file and the lines; that helps
just as much.

Security problems: please see [SECURITY.md](SECURITY.md).
